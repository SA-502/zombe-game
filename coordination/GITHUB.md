# GitHub والموقع

المستودع المشترك: https://github.com/SA-502/zombe-game

اللعبة المنشورة: https://sandstone-house-walk-xxtro.faresalhomaily966.chatgpt.site

جذر GitHub هو جذر هذا المشروع. يحفظ ملفات التعاون، ومصادر Blender وصادراتها، ومصدر اللعبة الموجود دائمًا في `outputs/house-game`. لا تنشئ لعبة ثانية ولا تستبدل هذا المسار بمستودع آخر.

لكل وكيل ملكية الملفات الموضحة في PROTOCOL.md. قبل التعديل اقرأ الحالتين، وبعد التسليم حدّث حالتك وشغّل `node coordination/update-project-index.mjs`. احفظ تغييراتك وحدها في commit ثم ادفعها إلى المستودع. سكربت PUSH_TO_GITHUB.cmd يدفع الـcommits الموجودة فقط. لا تستعمل force push، ولا تحفظ رموز الدخول في الملفات أو عنوان remote.

مجلد اللعبة يحتفظ بسجل Git مستقل خاص بمصدر Sites. هذا سجل للنشر من نفس الملفات، وليس نسخة تشغيل أخرى. لا تنقل أو تحذف `outputs/house-game/.git`. يملك وكيل البرمجة مزامنته ونشره عبر مهارة Sites. رفع commit إلى GitHub وحده لا ينشر الموقع؛ المعاينة المحلية تقرأ صادرات JSON المدعومة مباشرة.

يفحص GitHub Actions اللعبة ودمج Blender تلقائيًا عند دفع تحديث إلى main أو فتح pull request. هذا تحقق من المصدر؛ لا ينشر الإنتاج ولا يثبت جودة كل بند بصري بمفرده.
